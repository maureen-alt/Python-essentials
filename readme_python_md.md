## 📚 Covered Curriculum & Skills

### 🐍 Python Essentials 1
* **Fundamental Concepts:** Data types, variables, basic input/output operations, and arithmetic operators.
* **Control Flow:** Conditional execution (`if`, `elif`, `else`) and loop constructs (`while`, `for`).
* **Data Collections:** Managing and manipulating lists, tuples, and basic data structures.
* **Functions:** Defining custom functions, scope management, multi-parameter handling, and recursion.

### 🐍 Python Essentials 2
* **Modules & Packages:** Importing standard libraries (`math`, `random`, `platform`), building custom modules, and managing package structures.
* **Object-Oriented Programming (OOP):** Class design, instance attributes, methods, inheritance, polymorphism, and encapsulation.
* **Strings & Exception Handling:** String manipulation algorithms, advanced exceptions, and `try-except-else-finally` blocks.
* **File Processing:** Reading, writing, and handling text and binary files (`open`, `read`, `write`).
